## 4. 版型

- 深色編輯器風：深藍黑底、細格線背景（SVG），卡片 1px `#1e293b` 邊框、6px 圓角。
- 資訊密度高，但段落之間仍維持 80px 留白。
- 內容最大寬 1160px。
- 不放捲動動畫（技術受眾偏好快速瀏覽）。

## 5. 配色

| Token | Hex | 用途 | 對比 |

## 8. 原創文案大綱

- eyebrow：`// live coding · 120 min · free`
- H1：讓型別替你抓 bug：用 TypeScript 寫出好維護的 API
- lead：從零開始寫一個訂單 API，示範用型別描述資料、驗證輸入、處理錯誤，全程實機操作。
- 技術標籤：TypeScript、Node.js、Zod、REST
- CTA「報名直播」。
- 先備知識：
  - 寫過 JavaScript
  - 知道什麼是 HTTP API
  - 安裝 Node.js LTS
- 議程：
  - 00:00 專案初始化
  - 00:20 定義型別與 schema
  - 00:50 輸入驗證與錯誤處理
  - 01:20 測試
  - 01:45 Q&A
- 程式碼片段：原創的簡短示意碼（schema 定義與型別推導，10–15 行）。**不得從任何開源專案或文件複製**。
- FAQ：
  1. 會提供 repo 嗎？
  2. 需要 TypeScript 經驗嗎？
  3. 會錄影嗎？
  4. 用什麼編輯器？
