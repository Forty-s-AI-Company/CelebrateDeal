# 13｜電商數據導向報名頁

| 項目 | 內容 |
|---|---|
| 範本 id（暫定） | `webinar-ecommerce-data` |
| 原型 | 名次 13：數據導向標題 |
| 結構參考 | S4 WordStream 數字標題、Sprout Social 統計開場；S5 Calm 以統計建立問題感；S1 Perspective 單一數字 hero、A Better Life 明確收入目標 |
| 範本庫標籤 | 用途 `webinar`＋`sales`、風格 `vivid` |
| 實作批次 | 批次 3 |

## 1. 定位

- 適合：成果可以量化的主題；受眾習慣看數字做決策。
- 產業：電商、廣告投放、業務、行銷自動化。
- **誠實原則**：標題數字必須是「案例」或「目標」，要附條件說明，不得做收入保證。

## 2. 虛構主題與講者

- 講座：「客單價從 600 到 900：小電商的 4 個加購設計」
- 講者：鄭宇翔｜電商顧問、「小店成長數據室」主持人（虛構）

## 4. 版型

- 白底、高對比、粗字，橘色只用在數字、按鈕與重點。
- 網格感強：卡片有 1px `#e5e5e5` 邊框、無圓角或 4px 小圓角。
- 內容最大寬 1160px。
- 淺橘 `#fff4ea` 區塊用在數據列與參加禮。

## 6. 字型與字級

- 數字 `display-latin`（Space Grotesk）700；標題 `sans-tc` 900；內文 `sans-tc` 400。

| 層級 | 桌機 | 手機 |
|---|---|---|
| hero 數字 | 96 | 52 |
| H1 | 44 | 28 |
| H2 | 34 | 24 |
| 數據數字 | 48 | 36 |
| 內文 | 17 | 16 |

## 7. 互動

- 數據跳動。
- hero 數字從 600 跳到 900，只播一次；reduced motion 時直接顯示。
- inline 倒數。

## 8. 原創文案大綱

- hero 數字：「NT$600 → NT$900」
- H1：不多花廣告費，用 4 個加購設計把客單價拉高 50%
- 條件小字：「數字為虛構案例示意；實際成效依商品、流量與執行而異。」
- CTA「免費報名直播」。
- 數據（範本示意）：
  - 加購採用率
  - 平均客單價變化
  - 退貨率
  - 回購率
- 4 個加購設計：
  1. 湊免運門檻
  2. 搭配組
  3. 結帳頁小額加購
  4. 訂閱補貨
- 案例拆解：前後 3 項指標對照（虛構）。
- 參加禮（純展示）：
  - 加購商品挑選表
  - 免運門檻試算表
  - 結帳頁檢查清單
- FAQ：
  1. 適合哪些電商平台？
  2. 需要技術能力嗎？
  3. 回放
  4. 會推銷代操服務嗎？

## 9. 圖片與替代

- 報表截圖：SVG 繪製的儀表板（長條圖＋數字卡），放在 C-16 瀏覽器框中。批次 3 之前先用圓角 `image`。
- 講者：替換佔位人像。

## 10. 元件對應

- 現有：`columns_2`、`stats`、`icon_list`、`content_box`、`bulleted_list`、`form`、`faq`。
- 新增：C-01、C-02、C-04、C-06（inline）、C-10、C-11、C-16。

## 11. 驗收重點

- hero 數字 96px 在 1024 寬左欄（約 560px）內不得溢出；手機 52px 時「NT$600 → NT$900」可以換成兩行，但不得在數字中間斷開（數字串包 `white-space: nowrap` 的 span，整串寬度在 360 寬要 ≤ 320px，否則降到 44px）。
- 壓力測試的數字 `NT$1,280,000` 不得撐破數據卡。
