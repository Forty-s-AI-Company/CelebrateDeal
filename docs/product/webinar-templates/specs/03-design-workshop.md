# 03｜設計工作坊標準講座長頁

| 項目 | 內容 |
|---|---|
| 範本 id（暫定） | `webinar-design-workshop` |
| 原型 | 名次 3：標準講座長頁（你將學到＋講者＋議程時間軸） |
| 結構參考 | S16 Maven 區塊順序；S15 Zoom 議程與講者；S5 Sitecore、Salesforce；C2 CMoney 報名頁 SOP；C3 104 talks |
| 範本庫標籤 | 用途 `webinar`、風格 `natural` |
| 實作批次 | 批次 1 |
| 備註 | 中性骨架，可作為新的**預設報名頁**之一 |

## 1. 定位

- 適合：實作型工作坊、技能講座、需要說清楚「學什麼、怎麼進行、誰來教」的線上課。
- 產業：設計、寫作、簡報、教育訓練。
- 講者類型：專業工作者、講師。

## 2. 虛構主題與講者

- 講座：「零基礎也能做出好看的社群圖卡：2 小時排版實作工作坊」
- 講者：許晴｜品牌設計師，經營設計教學帳號「晴天排版室」（虛構）

## 4. 版型

- 內容最大寬 1120px；長頁節奏用底色交替：`#faf7f2` 與 `#ffffff`。
- 標題靠左對齊，報名表區塊與 FAQ 置中。
- 方格紙背景：首屏放極淡的方格線（SVG pattern，`#e7e1d8`），呼應設計主題。
- 區塊留白：桌機 96px、手機 56px。

## 5. 配色

| Token | Hex | 用途 | 對比 |
|---|---|---|---|
| bg | `#faf7f2` | 紙色底 | — |
| ink | `#1d1d1f` | 標題 | 15.75:1 |
| body | `#3f3f46` | 內文 | 9.77:1 |
| muted | `#6b6b73` | 註解 | 4.94:1 |
| primary | `#ff5b2e` | 按鈕底（**必須加 2px `#1d1d1f` 邊框**，因為按鈕底對頁面只有 2.90:1） | 按鈕字 `#1d1d1f` 5.44:1 |
| accent | `#2456e8` | 連結、時間軸節點、小字強調 | 5.50:1 |
| highlight | `#ffe9d6` | 標題螢光筆底線、卡片底 | ink 對它 14.33:1 |

## 6. 字型與字級

- 標題 `sans-tc` 900（粗黑、略緊字距 -0.01em）；內文 `sans-tc` 400；時間軸時間 `display-latin`（Space Grotesk）。

| 層級 | 桌機 | 手機 |
|---|---|---|
| H1 | 56／1.15 | 32／1.25 |
| H2 | 36 | 26 |
| H3 | 22 | 19 |
| 內文 | 18 | 16 |

## 7. 互動

- I-3 捲動上浮。
- 時間軸：捲到時節點依序亮起，只改 opacity；reduced motion 時直接全亮。
- 評價不自動播放。

## 8. 原創文案大綱

- eyebrow：線上實作工作坊｜2 小時｜附練習檔
- H1：不靠天分，用 4 個排版規則做出好看的社群圖卡
- lead：從字級、對齊、留白到配色，邊看邊做，結束時你會完成 3 張自己的圖卡。
- 主 CTA「報名工作坊」；次要連結「先看議程 ↓」。
- 適合誰：
  - 小店老闆
  - 社群小編
  - 想自己做簡報的上班族
  - 設計新手
- 你將學到（「能夠……所以……」句型，參考 S16 的成果寫法）：
  1. 能用 3 種字級建立層次，讓重點一眼被看見
  2. 能用格線對齊，讓版面整齊
  3. 能用留白控制閱讀順序
  4. 能用 60-30-10 配色法挑出不衝突的顏色
- 議程：
  1. 開場與暖身
  2. 規則一：字級
  3. 規則二：對齊
  4. 規則三：留白
  5. 規則四：配色
  6. 作品點評與 Q&A
- 講者：許晴，經歷寫具體案例，數據標示範本示意。
- 參加前準備：
  - 準備一台電腦
  - 安裝任一免費設計工具
  - 把時間加入行事曆
- 報名表標題「保留工作坊名額」，按鈕「免費報名」。
- FAQ：
  1. 一定要用電腦嗎？
  2. 有回放嗎？
  3. 練習檔怎麼拿？
  4. 完全沒基礎可以嗎？
  5. 可以開發票嗎？（依商家設定）

## 9. 圖片與替代

- 首屏：自製 SVG「作品拼貼」，3 張傾斜的圖卡示意，用色塊與假文字線，不用照片。
- 學員作品：6 張 SVG 圖卡佔位，標示「範本示意作品」。
- 講者：替換用佔位人像 SVG。

## 10. 元件對應

- 現有：`columns_2`、`icon_list`、`image_cards`、`testimonial_wall`、`form`、`faq`。
- 新增：C-01、C-02（featured）、C-03（vertical）、C-04、C-09（選用，批次 2 後在「參加前準備」加入行事曆按鈕）。

## 11. 驗收重點

- 時間軸在 360 寬：時間不得和標題擠在同一行造成溢出；中線不得穿過文字。
- 帶邊框的按鈕在手機寬 100% 時，邊框不得造成 1–2px 的水平溢出（`box-sizing: border-box`）。
