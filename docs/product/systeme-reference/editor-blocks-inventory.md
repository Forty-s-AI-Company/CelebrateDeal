## 實際加入行為

- Testimonials 的「quote icon + 文字 + 客戶照片／姓名／職稱」加入後生成 Section > Row > 各子元素，可各別選取編輯。
- Undo 移除整個 block、Redo 恢復；文字改為 `CelebrateDeal Editor Research`，Save 後 Preview 可見。
- 純視覺變體只做縮圖與用途盤點，未把每張 block 都加入，以避免污染測試頁。
- CelebrateDeal：九分類導覽與 block gallery 必做；第一階段每類至少一個代表 block，變體逐步補齊。
