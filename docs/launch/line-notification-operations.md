# LINE 通知的非正式環境驗收

WP-13 的本機收據不代表供應商送達或正式上線。僅使用固定 Sandbox、合成帳號與合成報名資料；不在文件或證據保存憑證、簽章、Cookie 或原始 webhook。

## 啟用前必要條件

- 在指定 Sandbox channel 啟用 Use webhook 及 **Webhook redelivery**。由維運提供不含憑證的設定確認；尚未確認時，外部送達驗收仍為 `WAITING_AUTHORIZATION`。
- 維持伺服器時鐘同步。簽章正確但事件時間超前的 unfollow 回覆 503，待供應商重送；不回覆假成功，也不改寫事件時間。
- 503 亦用於暫時性資料庫失敗。批次可能已部分套用，重送透過租戶、使用者雜湊、撤銷狀態與綁定時間的條件更新收斂。重送未啟用或超出供應商重送期間，不能承諾事件不遺失。
- 檢查報名者已完成原本驗證及 LINE 綁定，並在 Sandbox 證明提醒送達、封鎖後不再送出，以及通知通道選擇生效。這些供應商項目尚未驗證。

## 同意與撤銷語意

unfollow 會撤銷該商家的既有 LINE 綁定；帳號暫停時也記錄撤銷。follow 只表示追蹤或解除封鎖，不會自動清除撤銷紀錄，須重新走既有驗證綁定流程。

事件時間不早於最近一次明確綁定時才撤銷。這會比較 LINE 時鐘與伺服器綁定時間，兩者偏移是待 Sandbox 驗證的限制。資料庫已提交的新綁定不受較早事件重送影響。已進入供應商的發送不能撤回；worker 只在呼叫供應商前檢查最新撤銷狀態。

來源：[LINE 官方 webhook 文件](https://developers.line.biz/en/docs/messaging-api/receiving-messages/)。官方文件說明重送需額外啟用，事件可能重複或不依發生順序到達。

## 回滾

只回復 WP-13 webhook 與 helper 的精確 patch；不回復其他 WP、不清除已記錄的撤銷狀態、不自動重新啟用通知。外部 Sandbox 設定只由其 owner 調整。本輪未建立外部資源。
