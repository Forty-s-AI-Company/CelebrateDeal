# CelebrateDeal 台灣法遵檢查

## 何時用
功能涉及收集個資、LINE／Email 行銷、結帳頁文案、退款與解除權、預錄場與課程、發票、款項流向、聯盟推廣、倒數計時、腳本角色或聊天室、年齡限制時。這不是法律意見；標「需律師確認」者不得由工程自行定案。

## 檢查清單
- [ ] 個資告知（個資法 §8）：收集前顯示並記錄同意；交易通知與行銷分開同意；行銷訊息附免費退訂（§20）；刪除／去識別化有可執行流程。
- [ ] 7 日猶豫期（消保法 §18、§19）：結帳與商品頁在付款前顯示企業資訊、價格、解除權與申訴方式；排除解除權（數位內容）須事前告知＋勾選＋時間戳，預設保留猶豫期；佣金在猶豫期後才結算。（需律師確認）
- [ ] 電子發票：商品由商家開給消費者，平台服務費由平台開；封測用真實款項前先完成流程設計。（需會計師確認）
- [ ] 第三方支付：架構原則上平台不持有商家款項；先收後撥或代付聯盟佣金須評估登錄門檻。（需律師確認，門檻資料互相矛盾）
- [ ] 公平法廣告：倒數與庫存只能綁真實截止時間與真實庫存，不做每位訪客重置的假倒數；不偽造觀看數、購買通知、見證；預錄不可標成直播。
- [ ] AI／腳本角色：系統強制「官方腳本」「AI 助理」徽章與揭露句，商家不可關閉；不得有 `audience` 類「一般觀眾」型角色；腳本審核攔截第一人稱消費經驗。
- [ ] 聯盟：只做單層分潤，不對下線抽成，無入會費，UI 避免「下線」「組織獎金」；出款前需扣繳與補充保費資料。（需律師與會計師確認）
- [ ] 未成年：結帳年齡聲明，未滿 18 歲需法定代理人同意或封鎖。（上線前）
- [ ] 跨境子處理者（Supabase、Vercel、LINE）列於隱私政策。

## 禁止事項
- 不引用條號作為定案，一律註明「需對照全國法規資料庫原文」。
- 不為了轉換率移除告知、勾選或免責揭露；不複製競品話術。
- 不宣稱「合規」；只能說「已做檢查項目 X」。
