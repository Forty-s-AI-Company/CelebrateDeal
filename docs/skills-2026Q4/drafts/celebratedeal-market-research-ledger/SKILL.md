# CelebrateDeal 市場研究台帳

## 何時用
撰寫或更新 `docs/market-2026Q4/**`、競品比較、費率與法規摘要、GTM 假設，或在其他文件引用外部數據時。

## 必讀文件
- `docs/goal-plan-review-research-skills-20261017.md` §8.3 與 §9。
- `docs/market-2026Q4/reports/台灣直播導購 SaaS 市場研究 2026.md`（既有格式範例，含【推論】【舊】標記與缺口章節）。
- `docs/market-2026Q4/research_notes/`（原始筆記）。

## 檢查清單
- [ ] 每個事實一筆來源：URL、存取日（YYYY-MM-DD）、發布或更新日、可信度標籤（官方／法規原文／媒體／二手彙整／廠商自述／社群）。
- [ ] 區分「證據」與「推論」：推論句明標【推論】，不與數字混寫。
- [ ] 時效：費率、法規、平台政策超過 12 個月標【舊】並盡量找新版；法規必須註明版本或整編日期；條號與罰則數字標「需律師／會計師確認」。
- [ ] 同一指標有互相矛盾的來源時，兩者並列、寫出差異，不擇一默默採用（例如第三方支付門檻）。
- [ ] 競品只摘要與連結：不複製文案、截圖、價目表原文、設計稿；引文每份最多一句且短。
- [ ] 只用公開頁面與公開試用資訊；不登入競品、不建立帳號、不繞過付費牆、不使用他人憑證，不對外聯絡競品客戶。
- [ ] 沒有可靠數字的欄位寫「缺口」與原因（未取得、口徑不一、僅二手），不以推測值填補；缺口集中列在報告「缺口」章節。
- [ ] 個人資料與訪談內容只放去識別後摘要。

## 禁止事項
- 不引用搜尋摘要而未開原頁驗證；不使用無法追溯的數字。
- 不把競品的客戶見證或成效當成自家主張。
- 不把市場研究當作法律意見。

## 完成證據
台帳表（事實、來源、存取日、標籤）、缺口清單、被排除的矛盾來源說明；收據記錄實際搜尋或抓取了哪些頁面、哪些失敗（`TOOL_BLOCKED`）。
