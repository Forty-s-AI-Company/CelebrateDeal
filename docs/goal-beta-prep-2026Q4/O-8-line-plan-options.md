# O-8 LINE 官方帳號方案選項（2026-10-23 整理）

來源：LINE Biz-Solutions〈2026 年 LINE 官方帳號方案價格調整〉https://tw.linebiz.com/column/LINEOA-2026-Price-Plan/ （金額皆未稅）

| 方案 | 11-01 起月費 | 每月免費則數 | 可加購 |
|---|---|---|---|
| 輕用量 | 0 | 200 | 否 |
| 中用量 | 1,000（原 800） | 3,000 | 否，用完要升級 |
| 高用量 | 1,400（原 1,200） | 6,000 | 是：當月前 50,000 則 0.2 元／則，第 50,001 則起 0.15 元／則 |

- 免費且不計則數：加入好友歡迎訊息、一對一聊天、自動回應、AI 自動回應、Messaging API Reply API。
- 10-27 後仍使用中／高用量視為同意新價；不同意須於 10-27 前降為輕用量。
- 管理後台維護 2026-10-28 08:00 至 11-02（11/2 下午起陸續恢復）：不能新購、升降級、變更則數上限；11-24 08:00 至 11-25 另有維護。11-01 自動扣款成功者權益不受影響；建議 10-27 前加次要付款方式。
- 官方頁未寫明：群發是否按收件好友數計則數（一般做法按每位收件人計），以官方計費說明為準。

## 本專案決策（D-23 A）
封測商家用自己的官方帳號推播，費用由商家負擔；平台自己的官方帳號只做平台對商家的少量訊息。

建議：平台官方帳號 **10-27 前降為輕用量（NT$0）**；若已是輕用量則不需動作。若改採平台代發（D-23 B），再評估高用量 NT$1,400／月。
