# Webinar 範本最終驗收截圖

- 產生方式：`npm run qa:template-layout -- --templates=<20 個 Webinar 範本＋黑金＋4 個功能頁> --schedule=sample --widths=1440,390 --skip-rules=L-7 --jpeg --out=docs/ai-team/evidence/webinar-templates/final`
- `~sample` 表示 harness 的合成排程（約 3 天後 20:00 開播、開播前 1 小時截止報名），倒數、活動資訊列與截止提示都會顯示實際數值。
- 全頁截圖。畫面中段的固定報名列是截圖當下的捲動位置；左下「N」與右側「最新消息」是 next dev 的開發工具，不屬於頁面。
- 完整不跑版結果（8 種寬度＋壓力文案、排程與狀態）見 PR 說明；`report.json` 是本資料夾這輪的報告。
