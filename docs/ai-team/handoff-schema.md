# AI Team Handoff Schema

Handoff 是 checkpoint 的資料格式，不是每輪停機的硬性流程。小範圍工作可使用精簡格式；只有角色、scope、風險、授權或 Milestone 改變時才需要完整格式。

## 精簡格式

```text
AI_TEAM_HANDOFF
CURRENT_TASK_STATUS: IN_PROGRESS | COMPLETE | BLOCKED | WAITING_AUTHORIZATION
CURRENT_WORK_ITEM: <目前工作>
ACTUAL_RESULT: <實際結果>
EVIDENCE: <sanitized evidence 路徑或摘要>
NEXT_ACTION: <下一個高價值動作>
ROLLBACK: <本輪可回滾方式>
SAFETY_STATUS: PASS | BLOCKED
PLAN_REVIEW_STATUS: PASS | NOT_REQUESTED_QUOTA | LOGIN_REQUIRED | TOOL_BLOCKED | NOT_REQUIRED
GIT_PROMOTION_STATUS: NOT_REQUESTED | PUSH_ALLOWED | MERGE_ALLOWED | BLOCKED
PRODUCTION_DEPLOYMENT: MANUAL_APPROVAL_REQUIRED | NOT_AUTHORIZED
```

## 完整格式

```text
AI_TEAM_HANDOFF
CURRENT_TASK_RENAME: <必要時填寫>
CURRENT_TASK_STATUS: IN_PROGRESS | COMPLETE | PARTIAL | BLOCKED | WAITING_AUTHORIZATION
NEXT_TASK_REQUIRED: YES | NO
NEXT_TASK_TITLE: <必要時填寫>
NEXT_ROLE: SOL | TERRA | AGY | LUNA | USER | NONE
NEXT_MODEL: <模型或 NOT_APPLICABLE>
NEXT_ACTION: EXECUTE | QA | ACCEPTANCE | CONTINUE | PLAN_REMEDIATION | REQUEST_AUTHORIZATION | STOP
NEXT_REASON: <原因>
CURRENT_SCOPE_FILES: <檔案或資源>
PROPOSED_SCOPE_EXPANSION: <無或明確清單>
PRODUCTION_ACCESS_REQUIRED: YES | NO
USER_DECISION_REQUIRED: YES | NO
ROOT_CAUSE_CATEGORY: <分類>
PROCESS_STARTED: YES | NO
EXIT_CODE: <數字或 NOT_AVAILABLE>
EXCEPTION_TYPE: <類型或 NONE>
STDERR_SUMMARY: <sanitized 摘要，不得放 raw secret 或客戶資料>
ROOT_CAUSE_CONFIRMED: YES | NO
VALUE_CHECK: <產品、安全或 release 價值>
EXPECTED_MEASURABLE_OUTCOME: <預期結果>
ACTUAL_MEASURABLE_OUTCOME: <實際結果>
LOOP_STATUS: NONE | LOOP_DETECTED
AGY_FAST_STATUS: PASS | TOOL_BLOCKED | LOGIN_REQUIRED | NOT_STARTED
AGY_DEEP_FALLBACK_STATUS: PASS | TOOL_BLOCKED | LOGIN_REQUIRED | NOT_REQUIRED | NOT_STARTED
LUNA_HANDOFF_STATUS: PASS | FALLBACK_HANDOFF_REQUIRED | TOOL_BLOCKED | NOT_REQUIRED | NOT_STARTED
CLAUDE_PLAN_REVIEW_STATUS: PASS | NOT_REQUESTED_QUOTA | LOGIN_REQUIRED | TOOL_BLOCKED | NOT_REQUIRED | NOT_STARTED
GIT_PUSH_STATUS: NOT_REQUESTED | ALLOWED | BLOCKED
GIT_MERGE_STATUS: NOT_REQUESTED | ALLOWED | BLOCKED
PRODUCTION_DEPLOY_STATUS: MANUAL_APPROVAL_REQUIRED | NOT_AUTHORIZED
NEXT_PROMPT: <只有需要交接時提供>
```

## 使用規則

- 只記錄實際執行結果；未執行、失敗、timeout 或 login block 不得標成 PASS。
- Evidence 必須 sanitized，不得包含 `.env*`、Token、Cookie、正式 Secret、正式客戶資料、付款資料、raw request／response 或完整敏感 log。
- Handoff 可在 Goal 內連續更新，不代表必須停止或建立新 Task。
- 回滾必須只作用於本輪明確 ownership，不得碰既有使用者變更。
- Claude plan review 額度不足時記錄 `NOT_REQUESTED_QUOTA`，不可寫成 `PASS`；它不會阻擋 deterministic tests 或 Goal。
- Git promotion 只允許 `codex/*` 分支與受保護 PR；Production deploy 永遠維持 `MANUAL_APPROVAL_REQUIRED`。
