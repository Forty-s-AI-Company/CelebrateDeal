# 一頁式網站的自訂程式碼（商家說明草稿）

> 狀態：草稿，供客服與說明中心改寫。內容以 2026-10-27 的實作為準。

CelebrateDeal 的一頁式網站提供三種「自己寫程式碼」的方式：

1. **自訂程式碼元件**：在頁面任何欄位放一塊自己的 HTML、CSS 與 JavaScript。
2. **頁面自訂 CSS**：調整整個頁面的外觀。
3. **追蹤整合**：只填 GA4 與 Meta Pixel 的 ID，平台幫你放上官方追蹤碼。

為了保護你的訪客、你的後台帳號，以及同平台上的其他商家，這些功能都有一些限制，下面一一說明。

## 誰可以使用

- 只有商家的 **擁有者（owner）** 與 **管理員（admin）** 可以新增、修改或刪除自訂程式碼與頁面自訂 CSS，也只有他們可以發布含自訂程式碼的頁面。
- 頁面只要含有 JavaScript，儲存與發布的人都必須 **已完成 Email 驗證**。尚未驗證時，請到「驗證 Email」完成後再儲存。
- 每次儲存或發布自訂程式碼，平台都會留下紀錄（誰、哪個頁面、哪個欄位、大小），但不會記錄程式碼內容。

## 自訂程式碼元件

在編輯器左側的元件清單選「自訂程式碼」，拖進欄位後，在右側設定：

| 欄位 | 上限 | 說明 |
|---|---|---|
| HTML | 50 KB | 你的版面內容。 |
| CSS | 20 KB | 只影響這個元件自己的內容。 |
| JavaScript | 50 KB | 只在預覽與公開頁執行；編輯畫面不執行。 |
| iframe 說明 | — | 給螢幕報讀器使用者的名稱，例如「倒數計時」。 |
| 預設高度 | 40–20,000 px | 含 JavaScript 時會依內容自動調整；沒有 JavaScript 時固定為這個高度。 |

### 它在哪裡執行

自訂程式碼放在一個獨立的「沙箱」小視窗（iframe）裡，和頁面其他部分、CelebrateDeal 網站完全隔開：

- **可以**：用 `https://` 載入圖片、字型、樣式表與外部腳本（例如圖表或輪播套件）；使用行內 `<script>`；嵌入 `https://` 影片或其他 iframe；開啟新分頁（只在公開頁）。
- **不可以**：讀取或設定 Cookie、使用 localStorage／sessionStorage；讀取或修改頁面其他部分（`parent`、`top`）；把整個頁面導向別的網址；送出表單（`<form>`）；使用 `fetch`、`XMLHttpRequest`、WebSocket；使用 `alert()`、`confirm()` 等對話框；使用 `eval()` 或 `new Function()`。
- 沙箱內的程式碼看不到訪客在 CelebrateDeal 的登入狀態，也碰不到你的後台或其他商家。
- **這些限制不代表資料無法離開沙箱。** 沙箱仍可載入 `https://` 圖片（例如追蹤像素）、嵌入外部 iframe，也可以把自己這個小視窗導向外部網址；訪客在小視窗裡輸入的內容，你的程式碼都可能送出去。請只收集你有權收集的資料，並遵守個資規範；平台會在頁面最上方與最下方提醒訪客，不要在商家區塊輸入 CelebrateDeal 帳號密碼或付款資料。
- 頁面含 JavaScript 時，頁面最上方會顯示一行平台提醒，自訂 CSS 無法隱藏。
- 避免在 JavaScript 的字串中同時寫出 `<!--` 與 `<script`（例如組 HTML 字串時）：瀏覽器解析 HTML 時會把後面的內容當成腳本的一部分，讓你的腳本失效。需要時請拆開，例如 `"<!-" + "-"`。

### 沒有 JavaScript 時

如果 JavaScript 欄位是空的，這塊內容會以「完全不執行腳本」的方式顯示：HTML 只保留常見的排版標籤（標題、段落、清單、表格、連結、圖片等）與 `class`、`alt`、`title`、`href`、`src` 屬性，連結與圖片只接受 `https://` 或本站路徑。CSS 欄位照常套用。

### 開新分頁

公開頁上的自訂程式碼可以用 `window.open()` 或 `<a target="_blank">` 開新分頁。新分頁和原頁面之間的連結會被切斷，所以 `window.open()` 會回傳 `null`，新分頁也無法透過 `window.opener` 控制原頁面。編輯器與後台預覽不允許開新分頁。

### 表單與名單

沙箱內不能送出表單。要收集名單，請使用編輯器內建的「表單」元件，資料才會進入 CelebrateDeal 的名單與自動化流程。請勿在自訂程式碼中要求訪客輸入密碼或付款資料。

## 頁面自訂 CSS

在「頁面設定 → 自訂 CSS」輸入。上限 20 KB，輸入時會即時檢查，有錯誤時不會存入。

- 你的 CSS 只作用在頁面內容：每個選擇器前面會自動加上頁面內容的範圍。
- `html`、`body`、`:root` 會套用到頁面內容本身，例如 `body { background: #fafafa; }`、`:root { --brand: #e11d48; }`。
- 要指定某個元件，可以在元件設定的「進階 → HTML ID」設定 ID，再用 `#你的ID` 選取。
- 支援 `@media`、`@supports`、`@font-face`（字型網址必須是 `https://`，字型名稱不能用 `serif`、`system-ui` 等通用名稱，只能使用文字、數字、空白、底線與連字號）與 `@keyframes`。
- 你在 `@font-face` 宣告的字型名稱會自動加上 `cdm-` 前綴，同一份 CSS 裡 `font-family`／`font` 用到這個名稱的地方也會一併改寫，所以寫法不變；但透過 CSS 變數（`var(--font)`）引用的名稱不會改寫，請直接寫在 `font-family`。這是為了避免商家字型取代平台本身使用的字型。`@keyframes` 名稱同理加上前綴。
- `url()` 只接受完整的 `https://` 網址。

以下寫法會被拒絕，編輯器會顯示原因：

- `@import`、`@namespace`、`@charset`、`@layer` 與其他未列出的 @ 規則。
- `data:`、`javascript:`、相對路徑或 `http://` 的 `url()`，以及 `image-set()` 等用字串載入網址的函式。
- 反斜線（`\`）跳脫字元與 `<` 字元。
- `[value]`、`[nonce]` 屬性選擇器。
- 選取頁面內容以外的元素（例如 `body ~ footer`）、`html`／`body` 放在選擇器中間。
- 巢狀規則（例如在 `.a { }` 裡再寫 `.b { }`）、`expression()`、`behavior`、`-moz-binding`。

頁面最下方的平台說明（「本頁由商家建立…」與使用條款、隱私通知連結）在頁面內容之外，自訂 CSS 無法隱藏或遮住它；`position: fixed` 的元素也只會固定在頁面內容範圍內。

## 追蹤整合（GA4、Meta Pixel）

到「設定 → 追蹤設定 → 整合設定」：

| 欄位 | 格式 |
|---|---|
| Meta（Facebook）Pixel ID | 5–32 位數字 |
| GA4 評估 ID | `G-` 開頭，例如 `G-ABC123XYZ9` |
| Google Tag Manager ID | `GTM-` 開頭（目前不在公開頁載入，見下方） |
| TikTok Pixel ID | 英數字（目前只保存設定） |

勾選「在一頁式網站公開頁載入 GA4 與 Meta Pixel 瀏覽器追蹤碼」並開啟「記錄頁面瀏覽」後，平台會在你的公開頁放上 Google 與 Meta 的官方追蹤碼。平台不接受自行貼上的追蹤 script。

**為什麼不載入 Google Tag Manager？** GTM 容器可以執行任意自訂 HTML 與 JavaScript，若在公開頁載入，等於讓程式碼直接跑在 CelebrateDeal 的網域上，可能危及訪客與後台帳號。請改用 GA4 評估 ID 與 Meta Pixel ID。

## 平台暫停自訂程式碼時

遇到安全事件時，平台可能暫時停用自訂 JavaScript：

- 公開頁上的自訂程式碼元件只顯示 HTML 與 CSS，不執行 JavaScript；頁面自訂 CSS 也暫停套用。
- 編輯器預覽與 Funnel 管理頁同樣不執行 JavaScript。
- 這段期間無法新增或修改 JavaScript，但仍可刪除 JavaScript 或編輯其他內容。
- 恢復後，已發布的內容會自動照常運作，不需要重新發布。

## 常見問題

- **為什麼我的腳本讀不到 Cookie？** 沙箱刻意不提供 Cookie 與儲存空間。需要記住訪客狀態時，請改用平台的表單或追蹤整合。
- **為什麼 `fetch` 失敗？** 沙箱不允許 `fetch`／XHR／WebSocket。外部套件請用 `<script src="https://…">` 載入。
- **為什麼網址代稱不能用 `login`、`admin`、`support`？** 公開網址 `/lp/…` 不能看起來像平台的登入、後台、客服或驗證頁，也不能包含 `celebratedeal`。已經在使用的網址不受影響。
- **為什麼高度不對？** 含 JavaScript 時高度依內容自動調整（最高 20,000 px）；沒有 JavaScript 時請在「預設高度」設定。
- **為什麼編輯畫面沒有執行我的 JavaScript？** 編輯畫面只顯示 HTML 與 CSS，請用「預覽」或公開頁確認互動效果。
